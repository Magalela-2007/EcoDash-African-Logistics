# EcoDash: African Digital Logistics & Infrastructure Simulator

## Project Title
EcoDash - Solar-Powered Delivery Drone Simulation

## Project Description
EcoDash is an interactive 2D simulation where players control a 
solar-powered drone delivering medical supplies to rural Kenya.

## Installation Instructions
1. Clone this repository
2. Open index.html in a web browser
3. No installations required
